# AGENTS.md

Rules for AI coding agents working in this repository.

## Project

- What it is: a small in-memory bookings HTTP API and the first target of roy2392/ai-factory.
- Stack: Node.js 24, TypeScript with ESM, Fastify, Vitest, ESLint, Prettier, tsx and tsc.
- Layout: `src/app.ts` builds the app without listening; `src/server.ts` starts the HTTP listener.
- `src/routes/` contains HTTP handlers; `src/domain/` contains domain types and seeded data.
- `test/` contains Vitest tests using `app.inject`; `.github/` contains CI and factory wiring.

## Build and test

- Install: `npm ci` (Node 24; use `nvm use` if available).
- Develop: `npm run dev`.
- Build: `npm run build`; run compiled output: `npm start`.
- Fast tests: `npm test`.
- Lint and check formatting: `npm run lint`; format: `npm run format`.
- Typecheck: `npm run typecheck`.
- Full verification: `npm run verify` (lint, typecheck, test, build).
- **Run the build and tests before finishing.** Report exact commands and actual results in the PR.
  Never claim a check you did not run; report any unresolved failures.

## Conventions

- Use strict TypeScript, named exports, camelCase functions and PascalCase types.
- Use `.js` extensions for relative ESM imports in TypeScript source.
- Keep HTTP status codes and JSON error responses in routes; keep domain logic in `src/domain/`.
- Use Fastify's logger in the server. Keep app construction free of listening or process side effects.
- Data is in memory only; do not introduce a database unless the task requests one.
- Every behavior change comes with a Vitest test in `test/` using `app.inject`; close apps after tests.
- Document public API changes in `README.md` in the same PR.

## Scope

- Do only what the task asks. No unrelated refactoring, renames or dependency upgrades.
- For a task within a requirements issue, implement only that task.
- If ambiguous, state assumptions at the top of the PR description.

## Never

- Never edit `dist/`; it is generated by the build.
- Commit secrets, tokens or `.env` files.
- Disable or skip tests to make the build pass.
- Change `.github/workflows/` unless the task asks for it.
